# 功能里程碑 2026-10-22 —— master-pi 合并入 master

> 对应提交：master-pi 全部历史（至本次合并点）；标签：`milestone-2026-10`
> 覆盖三个子工程：`apps/backend`（NestJS 中枢）、`apps/body`（Electron 形体）、`apps/python-service`（Python 感知）

## 总览

数字秘书「Human」已完成**语音问答主链路**与**工具插件化底座**两大块：用户对着麦克风说话 → 感知系统转写 → 脑系统理解并流式回答 → 会话窗口展示；同时 Motor 工具体系完成插件化改造（类别契约 + 工程外加载），并接入首个真实 TTS 插件。Live2D 桌宠具备完整的表现协议（含音频口型同步能力）。

---

## 一、Sensory 感觉系统（apps/python-service）✅

- **sensory-hearing**：本地 ASR（模型动态加载、文件转写、流式会话转写）
- **VAD**：语音活动检测（`vad_start` / `vad_end` 事件驱动分段）
- **实时字幕流**：`sensory.hearing.caption_stream.*` 全套 topic（enable/disable/segment/started/stopped/error），经 Neural 总线供前端实时渲染
- **语音提问判定**：`sensory.hearing.question.finalized`——说完一句话自动判定为问题进入问答链路

## 二、Neural 神经系统（backend）✅

- **Neural Core**：Actor / Capability / Subscription 总线，统一 `BusMessage` 信封（command/query/control/event/response/error）
- **双接入**：WebSocket 网关（长连接、订阅推送）+ HTTP 网关（`POST /neural/trigger`、capabilities/subscriptions 管理）
- **三端共享协议**：`packages/neural-topics` topic 常量单一来源（TS + Python 同步）

## 三、Brain 脑系统（backend）✅（部分进行中）

- **cortex 皮层**：通用问答入口 `brain.cortex.ask.requested`（autoAsk）；口语改写 `rewrite`（completed 事件）；回答流式输出 `answer.stream.think/chunk/completed/failed`
- **language-center 语言中枢**：多 provider 模型接入（含本地 Ollama）；模型列表/校验/切换（`brain.language.models.*`）；OAuth provider 登录；`config.json` 模型配置体系
- **hippocampus 海马体（记忆）**：记忆写入/检索（RAG）/文档与分块管理/重建索引（`brain.hippocampus.memory.*`），问答默认注入记忆上下文；SQLite 存储 + 向量检索
- **agent（内嵌 pi）**：基于 `pi-agent-core` + `pi-coding-agent` 的编码代理；`brain.agent.run` / `coding.run` / 会话查询；toolPreset 机制（default / coding / coding_only 安全预设）
- **brain.init**：启动初始化流程

## 四、Motor 运动系统（backend）✅

- **motor-tool-runner 工具体系**：JSON 声明式工具配置（`~/.ai_secretary/tools/`）；builtin / process / shell 三种执行型；生命周期管理（start/stop/restart）+ 健康检测 + 进程托管；`motor.tool.execute/list/status/reload/install` 全套 Neural topic
- **工具插件化（本轮完成）**：
  - `packages/contracts` 类别契约包：契约注册表、轻量 Schema 校验器、`tts@1.0` 契约（synthesize / voices.list 必选，voices[].voiceId 强制非空）
  - **PluginResolver**：工程外插件加载（`~/.ai_secretary/plugins/node_modules`，支持 CJS/ESM、工厂/直接实例、顶层条件 exports）
  - **双重校验**：加载时（必选能力+版本）+ 调用时（契约基线 Schema 强制，防省略 Schema 绕过；fail-closed）
  - **按类别发现**：`motor.tool.list { category }`
  - Agent 工具桥接：Motor 工具自动转 pi AgentTool（ToolAdapterService）
- **motor-animation**：桌面自动化（聚焦应用文本输入）
- **`/tts-cache/:pluginId/:file`**：TTS 音频静态路由（CORS + realpath 防符号链接逃逸）

## 五、Body 躯体系统（apps/body）✅

- **Live2D 桌宠**：透明置顶无边框窗、拖拽移动、滚轮缩放、点击命中区触发动作/表情

- **Neural 接入**：ws/http 客户端连 backend
- Live2D TTS 测试对话框（patches/，待合入正式流程）
