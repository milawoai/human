## 2. 接口定义（新增/补齐）

```ts
// ── brain.language.model.switch（补实现）─────────
// request:  { profile: string, model?: string }
// effect:   config.json brain.defaultProfile = profile
//           profiles.json profiles[profile].defaultModel = model ?? 现值
// response: { success, data: { profile, model } }

// ── brain.language.providers.remote_models（新增 query）──
// request:  { profile: string }
// effect:   服务端以该档案的 baseUrl+key GET {baseUrl}/models（OpenAI 兼容）
// response: { success, data: { models: string[] } }   // 仅模型 id，密钥不出后端

// ── brain.language.providers.probe（新增 command）────────
// request:  { baseUrl: string }   // 无密钥探测（Ollama / 兼容端点）
// effect:   GET {baseUrl}/models → 失败则 GET {baseUrl}/api/tags（Ollama）
// response: { success, data: { ok, source: 'openai'|'ollama'|'none', models: string[] } }
```

安全铁律：密钥只在 backend 进程内使用；上述接口的响应不包含 baseUrl 以外的连接信息，更不含 key。
