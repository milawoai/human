## 二、总体目标与架构分层

遵循「宿主通用机制（纯 TypeScript，0 Python 强依赖）+ 外部可插拔 Python 决策模型插件（`qwen3-jev-mlx`）」的分层原则：

1. **契约层（`packages/contracts`）**：
   - 新增 `router@1.0`（`ROUTER_CONTRACT_V1`）类别契约，定义 `router.decide` 必选同步能力（输入 `userText`、`contextSummary`、`candidates`、`fewShotExamples`、`topK`、`threshold`；输出 `selectedToolIds`、`scores`、`latencyMs`、`model`）。
2. **宿主基底节模块（`apps/backend/src/brain/basal-ganglia/`）**：
   - `ToolRoutingLogStore`：基于 `~/.ai_secretary/sqlite/session.db` 建立 `tool_routing_logs` 表，记录每次路由预测集 $R$、主脑实际调用集 $A$、是否调用了 `tool_search`、以及自动判定的 `is_false_negative`（错题本），并提供基于词汇/字符重合度的毫秒级历史相似错题 Few-shot 检索。
   - `ToolRouterService`：
     - 支持三种模式（通过环境变量 `HUMAN_TOOL_ROUTER_mode` 或配置控制，默认 `shadow`）：
       - `off`：不执行路由，直接返回全量工具；
       - `shadow`（默认）：调用已启用的 `router@1.0` 插件（无插件时回退到宿主内置轻量词汇打分器）记录预测与耗时，但向 `BrainAgentService` 仍返回全量工具；会后自动对比主脑实际工具调用并写入 `tool_routing_logs`；
       - `active`：当候选工具数超过阈值（默认 `minCandidatesForRouting = 4`，可配置）时，仅保留路由器选出的 Top-K 工具 + 1 个固定兜底元工具 `tool_search`；当主脑调用 `tool_search({ query, executeTool, executeParams })` 时，可实时检索全量工具池并直接代理执行漏选工具，会后自动将该漏选工具记入 `is_false_negative = 1` 错题本！
     - 暴露 Neural 总线查询/命令接口（或供 `BrainAgentService` 直接调用）：`brain.router.decide`、`brain.router.logs`（查看路由统计与错题本）。
3. **BrainAgent 唯一切口接入（`apps/backend/src/brain/agent/brain-agent.service.ts`）**：
   - 在 `buildTools()` 中接入 `ToolRouterService.prepareToolsForRun()`；
   - 在 `handlePrompt()` 运行结束后调用 `ToolRouterService.recordRunOutcome()`，扫描本轮新增消息中的 `toolCall`（含 `tool_search` 调用），完成自进化闭环。
4. **外部本地 `Qwen3-1.7B (MLX)` 决策插件（`/Users/zhou/Desktop/human-tools/router/qwen3-jev-mlx`）**：
   - 严格遵循 `插件创建与Python环境规范.md`：
     - `.python-version`（`3.12`）+ `pyproject.toml`（`mlx-lm>=0.22.0`, `huggingface-hub>=0.26.0`）
     - `engine.py`：加载 `mlx-community/Qwen3-1.7B-4bit`，关闭 thinking（`<think>\n\n</think>\n`），通过单次前向传播（Single Forward Pass Logits）提取每个候选工具的相关性得分与校准概率 $P = \sigma(\Delta z / T)$；
     - `worker.py`：常驻 `stdin/stdout` JSON-lines 协议；
     - `index.js`：实现 `router@1.0` 契约的 `router.decide` capability；
     - `scripts/install.mjs` 与 `scripts/verify-human.mjs`：安装软链、配置备份与端到端验证。
