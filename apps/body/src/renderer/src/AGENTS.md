# Renderer 强制入口

本目录所有页面/组件/样式/脚本继承 [Body 统一主题契约](../../../AGENTS.md#统一主题契约强制)。任何 code agent 均须遵守。

- 新界面消费中央 `--human-*` 语义颜色、字号和字体；优先复用已有组件。新增视觉角色或预设只改中央主题定义与桥接。
- 不写固定颜色/字号/字体，不使用旧主题别名或固定色板 utility 类，不在页面重定义主题、单独切深浅色；行内/动态样式同样适用。
- `transparent`/`currentColor`/继承色可用；布局尺寸与模型/图片本体不是主题配色。启动/桌宠外画布保持透明。
- 验证 `yarn verify:theme-usage`；涉及视觉变化再跑 `yarn verify:theme` 并检查真实主题/大字号。不得删门禁、扩大基线或靠动态拼接绕过。
- 遗留违规只许减少，修复后 `yarn theme:prune-baseline`；新文件没有豁免。
